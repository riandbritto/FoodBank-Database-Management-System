# Food Bank Database Management & Analytics System

## Project Overview

A SQL Server database management project designed to support food bank operations, including donor registration, donation tracking, inventory management, and food distribution.

The project demonstrates relational database development, SQL programming, transaction management, and data integrity controls.

## Technologies Used

- Microsoft SQL Server
- T-SQL
- Stored Procedures
- SQL Views and Functions
- Database Triggers
- Transaction Management
- Database Indexing

## Key Features

**Donor Management**
- Register and maintain donor records
- Retrieve donor donation histories
- Manage donor-related transactions

**Donation Management**
- Record monetary and item donations
- Track donation information
- Generate donation summaries

**Inventory Management**
- Update inventory quantities
- Track available inventory
- Calculate inventory values and remaining stock

**Food Distribution**
- Support distribution processing
- Track orders and distributed items
- Maintain operational records

**Database Reliability**
- Implement transaction handling and error management
- Support audit tracking through triggers
- Use SQL functions and views for data retrieval and reporting

## Project Structure

- `FoodBankDB_DBO_v3.sql` — Database objects
- `FoodBankDB_psm_v4.sql` — Stored procedures and functions
- `FoodBankDB_inserts_v3.sql` — Data insertion scripts
- `FoodBankDB_indexes_script_v1.sql` — Database indexes
- `FoodBankDB_encryption_v2.sql` — Database security scripts
